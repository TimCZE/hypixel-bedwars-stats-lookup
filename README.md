# Hypixel Bedwars Stats Lookup

A small, non-monetized Discord bot for looking up Hypixel Bedwars stats by Minecraft username. Made for personal use and for a few friends.

> **Status:** early development.

## How it uses the Hypixel API

- Only the public endpoints are used
- All requests are made from my own server using a single API key that I own
- The API key is read from an environment variable and is never committed to this repository, shown to users or sent to third parties
- Users are never asked to provide their own API keys
